## 아직 답이 필요한 것 — 2건

### A. 가족에 누가 합류했는지 어떻게 확인하나

가족 세부 화면은 **생성할 때 입력한 항목 전부**(가족명·메모·프로필 이미지)를 노출하기로 정해졌습니다.
그런데 여기에 **구성원 목록이 빠져 있습니다.**

초대 코드로 합류하는 방식이므로, 코드를 아는 사람은 누구나 들어올 수 있습니다.
현재 설계로는 **모르는 사람이 들어와도 아무도 확인할 수 없습니다.**

> **결정할 것**: 가족 세부 화면에 보호자 목록을 함께 노출할지. 노출한다면 이름만 / 이름+관계.

### B. 호칭 목록을 늘릴지

`기타`일 때 "보호자"로 표기하는 것은 정해졌습니다.
남은 것은 목록 자체입니다. 현재 **보호자 / 딸 / 아들 / 손녀 / 손자 / 기타** 여섯 개뿐이라
**배우자(어르신의 남편·아내), 사위, 며느리, 조카, 형제자매**가 전부 `기타` → "보호자"로 표시됩니다.

> **결정할 것**: 위 호칭들을 목록에 추가할지.

## 프론트에서 유의할 점

확정 사항 중 화면 구현에 직접 영향을 주는 것들입니다.

| 항목 | 유의사항 |
| --- | --- |
| 참여 막대 | 점수를 쓰지 않으므로 막대 높이는 **참여함 / 안 함 2단계**만 가능합니다. 높이를 여러 단계로 나눌 수 없습니다 |
| 컨디션 링 | 채우는 값은 점수가 아니라 **이번 주 참여일 수**입니다 |
| 어르신 답변 버튼 | 서버가 중복을 막지 않고 취소 API도 없습니다. **연타 방지는 프론트에서** 처리해야 합니다 |
| 추억 목록 | 1년이 지난 추억은 목록에서 사라집니다. 빈 상태 문구가 필요합니다 |
| 타 보호자 표기 | 관계 라벨을 단독으로 쓰면 안 됩니다. 반드시 어르신 이름을 앞에 붙입니다 |
| 마지막 접속 | 홈 화면 전용입니다. 리포트 등 다른 화면에는 넣지 않습니다 |
